# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be specific, and assume good faith. Harassment, personal
attacks, and discriminatory language are not acceptable in issues, pull requests,
discussions, or any other project space, and get you removed from the project.

## Reporting

Report conduct concerns privately to
[security@moqom.cloud](mailto:security@moqom.cloud). Reports are read by the
maintainers of Elliott Wave LLC, kept confidential, and answered. Enforcement
follows the Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
